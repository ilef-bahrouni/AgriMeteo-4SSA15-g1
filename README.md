
# 🌱 AgriMeteo

## 📌 Project Description

AgriMeteo is a smart agricultural weather management application designed to help farmers make better decisions using meteorological data and intelligent irrigation recommendations.

The project is based on a microservices architecture, with an Angular frontend and a Spring Boot backend.

## 🏗️ Architecture

- **Frontend:** Angular
- **Backend:** Spring Boot
- **Architecture:** Microservices
- **Database:** PostgreSQL

## ⚙️ Technologies Used

### Frontend
- Angular
- TypeScript
- HTML
- CSS

### Backend
- Java
- Spring Boot
- Spring Data JPA
- Maven
- PostgreSQL
- REST API

## 🚀 Main Features

- Weather data management
- Irrigation management
- Irrigation recommendations
- User management
- File management

## 👥 Project Team

Developed as part of the 4SA project at ESPRIT.

## ▶️ Installation

Clone the repository:

```bash
git clone https://github.com/ilef-bahrouni/AgriMeteo-4SSA15-g1.git
```

Open the project in your IDE.

Install the frontend dependencies:

```bash
npm install
```

Run the Angular application:

```bash
ng serve
```

Run each Spring Boot microservice separately using Maven or IntelliJ IDEA.
